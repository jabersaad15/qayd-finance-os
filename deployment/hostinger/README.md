# نشر QAYD على VPS Hostinger

هذه الحزمة مخصصة لخادم Hostinger KVM مع Docker/Easypanel. لا ترفع التطبيق عبر FTP إلى `public_html` لأن الخادم يحتاج Node.js وقاعدة بيانات دائمة.

## معاينة آمنة قبل تغيير النطاق

انسخ المشروع إلى دليل تطبيق آمن على VPS، ثم أنشئ `deployment/hostinger/runtime.secrets` من الملف `runtime.env.template` مع كلمات مرور قوية. شغّل:

```bash
docker compose --env-file deployment/hostinger/runtime.secrets -f deployment/hostinger/docker-compose.vps.yml up -d --build
```

تعمل المعاينة على منفذ التطبيق المعرّف في البيئة. لا تحوّل DNS قبل التحقق من الدخول المحلي ورفع مستند وإصدار فاتورة.

## بيانات الإنتاج

قبل إدخال أي بيانات من النظام الحالي، خذ نسخة احتياطية قابلة للاستعادة. شغّل ترحيلات Drizzle على قاعدة MariaDB الجديدة أولاً، ثم استورد نسخة البيانات بعد مراجعة توافقها. بيانات `runtime.secrets` تبقى على VPS فقط ولا تدخل Git.

## متطلبات التحويل النهائي

قبل استخدام النطاق الرئيسي يجب ضبط HTTPS و`PUBLIC_APP_URL` على عنوان المنصة العام، ثم إعادة تشغيل خدمة التطبيق. لا تفعّل التحويل النهائي قبل اختبار الحسابات والصلاحيات والمستندات على بيئة المعاينة.
