# التحقق البصري لمسار المحاسبة

تمت مراجعة مسار `/accounting` في بيئة التطوير بتاريخ 2026-08-15. أظهر المسار قائمة التنقل العربية واتجاه RTL وكتل المحاسبة والأستاذ العام ضمن مساحة عمل كونسيدرا. كانت استعلامات الأرصدة في حالة تحميل وقت الالتقاط، لذا يظل التحقق الوظيفي المعتمد على البيانات مغطى بفحص TypeScript ومجموعة Vitest، بما فيها اختبار قواعد احتساب أرصدة القوائم المالية.

لا يُفسَّر ظهور حالة التحميل كغياب للتقرير؛ فالبيئة المسجلة للاختبار كانت تسترجع البيانات المحمية أثناء الالتقاط. لا توجد أخطاء TypeScript أو أخطاء تشغيل جديدة مرتبطة بواجهة التقارير بعد الإصلاح.

أعيدت محاولة التحقق عبر المسار المنشور والمسار التطويري. كلاهما وصلا إلى بوابة الدخول لأن جلسة متصفح الاختبار لا تحمل جلسة المستخدم المحمية، ولذلك لم تُنفذ عملية دخول أو إنشاء بيانات تجريبية. بقيت المراجعة الوظيفية معتمدة على فحوص TypeScript وVitest، بينما يحتاج التحقق البصري من صفوف التقرير الحية إلى الدخول بحساب يملك مساحة العمل وقيوداً مرحلة.
