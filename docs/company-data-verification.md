# توثيق مطابقة بيانات الشركة

تمت مطابقة بيانات بطاقة معلومات **شركة كونسيدرا القابضة** المقدمة من مالك المنصة مع الحقول التشغيلية التالية قبل التحديث.

| الحقل | القيمة المعتمدة | موضع الحفظ |
|---|---|---|
| الاسم العربي | شركة كونسيدرا القابضة | `companies.legalNameAr` |
| الاسم الإنجليزي | Consedra Company Holding | `companies.legalNameEn` |
| السجل/الرقم الوطني الموحد | 7052330474 | `companies.commercialRegistration` و`companies.unifiedNumber` |
| رقم التسجيل الضريبي | 314352144600003 | `companies.vatNumber` وملف VAT |
| المدينة | الرياض | `companies.city` |
| العنوان الوطني | ARMA3887، طريق المطار 3887، الحي والرقم الفرعي والرمز البريدي كما وردت في البطاقة | `companies.nationalAddress` |
| دورية VAT | ربع سنوي | `taxProfiles.filingFrequency` |

لا تُسجّل معلومات البطاقة غير اللازمة للتشغيل، مثل رقم الشهادة أو تاريخ الإصدار، كبيانات امتثال مؤكدة ما لم تُخصّص لها حقول وسياسة تحقق مستقلة.
