# Implementation Roadmap

## المرحلة الحالية: نواة تشغيلية قابلة للاختبار

تُبنى أولاً الحواجز البنيوية التي يصعب تغييرها: العزل متعدد المستأجرين، سياق الصلاحيات، محرك القيد الحتمي، سجل التدقيق، سياسات الامتثال ذات الإصدارات، والمبالغ العشرية. يتبعها مسار مبيعات مكتمل من العميل إلى العرض إلى الفاتورة إلى القيد والتحصيل والتقرير. يوضع تكامل ZATCA كموصل قابل للاختبار لا ادعاء تشغيل إنتاجي.

| الموجة | الناتج | معيار القبول |
| --- | --- | --- |
| 1 | الجداول الأساسية، الصلاحيات، إعداد الشركة، وثائق التصميم | لا إجراء مالي بلا مستأجر وصلاحية |
| 2 | العملاء، الخدمات، العروض، الفواتير، فحص ما قبل الإصدار | عرض يتحول إلى فاتورة بتسلسل وقواعد صحيحة |
| 3 | القيود، التحصيل، الأستاذ، ميزان المراجعة، لوحات أساسية | كل مبلغ يمكن تتبعه للمستند والقيد |
| 4 | VAT، المستندات، بنية موصل ZATCA، المصروفات والبنوك | فشل تكامل خارجي لا يفسد الدفتر |
| 5 | AI المقيد، الإشعارات، الاستيراد، اختبارات موسعة | AI يعرض المصدر ولا ينفذ عمليات حساسة |

تُنشر أي خطة تعتمد على القواعد المحاسبية المعتمدة في السعودية وفق الإصدارات التي تقرها SOCPA؛ وتتطلب حوكمة التحديث مراجعة امتثال قبل تفعيل الإصدار في شركة إنتاجية. [1] [2]
