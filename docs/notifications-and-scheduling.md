# الإشعارات والمهام الدورية

تستخدم المنصة جدول `outboxEvents` كمصدر موحّد للأحداث المالية القابلة للتسليم، مثل اعتماد فاتورة. لا تستخدم المنصة مؤقتات داخلية أو عمليات `setInterval`، لأن بيئة التشغيل قابلة للتوسع والإيقاف عند الخمول.

## التفعيل الإنتاجي

بعد نشر النسخة، يُنشأ معالج HTTP ضمن المسار `/api/scheduled/*` ويُستدعى عبر مهمة Heartbeat. يجب أن يتحقق المعالج من هوية المهمة عبر `sdk.authenticateRequest` وأن يرفض أي طلب لا يحمل `isCron` و`taskUid`. تُحدَّث السجلات باستخدام `taskUid` المخزن في سجل الإعداد المالك للمهمة، لا باستخدام اسم المهمة أو بيانات الطلب.

| النوع | الاستخدام المخطط | الضابط |
|---|---|---|
| إشعار مواعيد VAT | تنبيه مسؤول الشركة قبل موعد الفترة الضريبية | مهمة Heartbeat مع سجل إعداد مملوك للشركة |
| تقارير دورية | ملخص يومي أو أسبوعي للقيود المرحلة | يولّد من تقارير النظام ويُسجل في outbox |
| طلبات اعتماد معلقة | تذكير بمستندات تتجاوز حد الاعتماد | يمنع الاعتماد الذاتي ويُرسل للمخول فقط |

لا تُنشأ مهمة مجدولة من بيئة التطوير. يتطلب تشغيل أي مهمة نشر المشروع أولاً، ثم ضبط المهمة بستة حقول cron بتوقيت UTC، ومراجعة سجل التنفيذ من لوحة الإدارة.

تم نشر مسار التذكير الآمن. لم تُفعّل مهمة شركة فعلية لأن قاعدة البيانات لا تحتوي حالياً على شركة مهيأة؛ وعند إنشاء مساحة عمل، ينشئ إعداد التذكير مهمة Heartbeat ويربط معرفها بسجل الشركة قبل التنفيذ.
