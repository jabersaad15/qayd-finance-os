# Security and Privacy Architecture

تطبّق المنصة دفاعاً متعدد الطبقات: مصادقة الجلسة المدمجة، تفويض خادمي لكل إجراء، تنقية مدخلات، قيود قاعدة بيانات، تشفير النقل، إدارة أسرار، تخزين ملفات معزول، مراقبة، وسجل تدقيق. يحد نظام حماية البيانات الشخصية من جمع البيانات إلى الغرض المحدد، ويؤكد الحقوق في العلم والوصول والتصحيح وطلب الإتلاف ضمن الاستثناءات النظامية، مع وجوب تدابير تنظيمية وإدارية وتقنية للحماية. [1]

| المجال | الضابط المعماري |
| --- | --- |
| المصادقة | جلسات آمنة، سياسات كلمة مرور/MFA عند تفعيل مزود الهوية، تعطيل الجلسات عند المخاطر |
| التفويض | فحص RBAC + صلاحية دقيقة + tenant scope + سياسة اعتماد في الخادم |
| خصوصية البيانات | minimization، purpose tags، access logging، طلبات تصحيح/تصدير، حفظ متوافق مع السجلات المالية |
| المستندات | تخزين كائنات، روابط مؤقتة، نوع/حجم مُتحققان، فحص خبيث قبل إتاحة الملف |
| الأسرار | لا مفاتيح أو شهادات في الكود أو سجلات التدقيق، تدوير، صلاحية أقل |
| الاستمرارية | نسخ احتياطي مشفر، أهداف RPO/RTO موثقة، اختبار استعادة دوري |
| المراقبة | أحداث دخول، تصعيد صلاحية، تكامل ZATCA، وظائف فاشلة، ونشاط مشبوه |
